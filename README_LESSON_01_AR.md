## تشغيل المشروع

افتح PowerShell ونفّذ:

```powershell
Set-Location -LiteralPath 'C:\Users\Pc\Desktop\FastAPI-Lesson-01'
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

البيئة الافتراضية والاعتمادات مثبتة بالفعل على جهازك. أبق نافذة الطرفية مفتوحة أثناء التجربة. لإيقاف الخادم اضغط `Ctrl+C`.

إذا كنت تستخدم النسخة المضغوطة على جهاز آخر، استخرجها داخل مجلد ثم نفّذ `uv sync --locked` من داخله قبل أمر التشغيل. الأرشيف لا يحتوي على البيئة الافتراضية؛ تعاد تهيئتها من الملفات الأصلية. ثبّت Python المناسب وuv إذا لم يكونا موجودين على ذلك الجهاز.

العناوين بعد التشغيل:

- `http://127.0.0.1:8000/`: عنوان أول منشور داخل HTML.
- `http://127.0.0.1:8000/posts`: الاستجابة نفسها عبر مسار آخر.
- `http://127.0.0.1:8000/api/posts`: المنشوران كاملان بصيغة JSON.
- `http://127.0.0.1:8000/docs`: واجهة Swagger UI.
- `http://127.0.0.1:8000/redoc`: واجهة ReDoc.
- `http://127.0.0.1:8000/openapi.json`: وصف API بصيغة OpenAPI JSON.

## شرح main.py بحسب مواضعه

### السطران 1 و2 استيراد مكونات الإطار

`FastAPI` الفئة التي ننشئ منها كائن التطبيق. و`HTMLResponse` فئة استجابة تقدم المحتوى بوصفه HTML. الاستيراد يجعل الاسمين متاحين في الملف، ولا يبدأ خادم HTTP وحده.

### السطر 4 إنشاء التطبيق

`app = FastAPI()` ينشئ كائن ASGI الذي سيقدمه الخادم. هذا الكائن يحتفظ بالمسارات وإعدادات التوثيق ويشارك في معالجة الطلبات. لا يعني إنشاؤه أن المنفذ 8000 بدأ الاستماع؛ الخادم هو الذي يتولى ذلك.

### الأسطر 7 إلى 22 بيانات المنشورات

`posts` قائمة تحتوي قاموسين. كل قاموس يصف منشورًا بحقول `id` و`author` و`title` و`content` و`date_posted`.

`list[dict]` إشارة نوع، وليست Schema تحقق تفصيلية لكل حقل. البيانات موجودة في ذاكرة العملية. لم تضف المحاضرة الأولى قاعدة بيانات أوقراءة من JSON/CSV. عند إعادة تحميل Module ينشئ الكود هذه القائمة من جديد.

### الأسطر 25 إلى 28 مسارا HTML

يوجد Decorator للمسار `/` وآخر للمسار `/posts` فوق الدالة `home`. لذلك تسجل الدالة نفسها لمعالجة GET على المسارين. تركيب Decorators يبدأ من الأقرب للدالة؛ تسجل `/posts` ثم `/`، لكن كلاهما متاح بعد اكتمال تحميل الملف.

`response_class=HTMLResponse` يحدد شكل الاستجابة كنص HTML. و`include_in_schema=False` يستبعد هذين المسارين من OpenAPI ومن قائمة العمليات داخل واجهات التوثيق؛ لا يعطلهما ولا يجعلهما خاصين أوآمنين بالمصادقة.

داخل `home` يعاد عنوان أول منشور داخل عنصر `h1`. `posts[0]` تعني أول قاموس، و`['title']` تعني قراءة قيمة عنوانه. وf-string تضع القيمة داخل النص. هذه الدالة لا تعرض المنشورين كاملين، ولا تستخدم Jinja2 بعد.

### الأسطر 31 إلى 33 مسار JSON

يسجل Decorator المسار `GET /api/posts` للدالة `get_posts`. تعيد الدالة القائمة الموجودة في الذاكرة. يتولى FastAPI تحويلها إلى استجابة JSON قابلة للإرسال عبر HTTP. لذلك لا تحتاج الدالة هنا إلى تحويل القائمة إلى نص JSON يدويًا.

## تسلسل بدء التشغيل

1. تشغّل الأمر من مجلد المشروع حتى يستطيع Python العثور على Module المسماة `main`.
2. يُستخدم مفسر `.venv`، ثم تشغل `-m uvicorn` وحدة Uvicorn ضمن هذه البيئة.
3. يفسر Uvicorn القيمة `main:app`: استورد Module `main` ثم استخدم الكائن `app` منها.
4. ينفذ Python كود المستوى الأعلى في `main.py`: الاستيرادات، ثم إنشاء التطبيق، ثم إنشاء بيانات المنشورات.
5. عند تعريف الدوال تطبق Decorators وتسجل العلاقة بين HTTP method والمسار والدالة.
6. يجهز الخادم دورة حياة التطبيق ويبدأ استقبال الطلبات على `127.0.0.1:8000` عندما يكتمل بدء التشغيل. قد تختلف تفاصيل تجهيز المقبس والعمليات مع وضع إعادة التحميل.
7. ينتظر التطبيق طلبات المستخدمين. لا تنفذ `home` و`get_posts` لمجرد تعريفهما.

`--reload` وضع تطوير يراقب الملفات. قد ترى عملية مراقبة وعملية خادم، ويعاد تحميل التطبيق عند تغييره. هذا لا يعني أن ملف التطبيق يعاد تحميله لكل طلب عادي.

## تسلسل GET /

```text
المتصفح يرسل GET /
    ↓
Uvicorn يستقبل HTTP ويقدمه للتطبيق عبر ASGI
    ↓
مطابقة GET مع المسار /
    ↓
FastAPI يستدعي home()
    ↓
قراءة title من أول عنصر في posts
    ↓
إرجاع <h1>FastAPI is Awesome</h1>
    ↓
تجهيز HTMLResponse بحالة 200 ونوع text/html
    ↓
إرسال الاستجابة إلى المتصفح وعرض العنوان
```

يحدث المسار نفسه عند طلب `/posts` لأن الدالة المسجلة هي نفسها.

الدالتان مكتوبتان باستخدام `def`؛ يتولى FastAPI التعامل مع Path Operations العادية باستخدام Thread Pool. لم تضف هذه المحاضرة منطق Async خاصًا أوطلبات خارجية.

## تسلسل GET /api/posts

```text
العميل يرسل GET /api/posts
    ↓
مطابقة المسار مع get_posts()
    ↓
إعادة القائمة الموجودة في الذاكرة
    ↓
FastAPI يجهز استجابة application/json بحالة 200
    ↓
العميل يستقبل قائمة JSON تحتوي المنشورين
```

الطلب لا يقرأ `snippets.txt` ولا يعيد إنشاء البيئة أوتثبيت الاعتمادات. كما أنه لا يستدعي `home`؛ لكل مسار الدالة المطابقة له.

## تسلسل فتح التوثيق

صفحة `/docs` تقدم واجهة Swagger UI، التي تستخدم `/openapi.json` لعرض عقد API. المسار الظاهر من التطبيق هو `/api/posts` فقط لأن مساري HTML مستبعدان من المخطط. زر Try it out ينفذ طلبًا فعليًا إلى المسار عند استخدامه.

طلب عنوان غير مسجل مثل `/not-found` ينتج استجابة 404. لم يضف الدرس معالج أخطاء خاصًا لهذه الحالة.

## ما تم تنفيذه في هذه المرحلة

- إنشاء تطبيق FastAPI.
- تعريف بيانات منشورين في الذاكرة.
- عرض عنوان أول منشور عبر مسارين HTML.
- تقديم بيانات المنشورين عبر مسار JSON.
- استخدام توثيق FastAPI التلقائي مع إخفاء مساري العرض من مخططه.

الحالة النهائية لهذه المحاضرة لا تتضمن إنشاء منشورات عبر POST أوتعديلها أوحذفها، ولا تتضمن قاعدة بيانات أومصادقة أوقوالب Jinja2. لم أضف هذه الوظائف إلى الكود.

## التحقق الذي نُفذ

شُغل Uvicorn محليًا على منفذ اختبار منفصل ثم أُرسل HTTP حقيقي للتحقق من:

- `/` و`/posts`: حالة 200 ومحتوى HTML المتوقع.
- `/api/posts`: حالة 200 ونوع JSON ووجود المنشورين.
- `/openapi.json`: وجود `/api/posts` وحده ضمن مسارات التطبيق الموثقة.
- `/docs` و`/redoc`: حالة 200.
- `/not-found`: حالة 404.

كما تحققت المطابقة الثنائية لملفي `main.py` و`uv.lock` مع المصدر. أُوقف خادم الاختبار بعد انتهاء التحقق؛ استخدم أمر التشغيل أعلاه لتبدأ جلستك الخاصة. فحص استجابة صفحات التوثيق لا يعني اختبار تحميل ملفات الواجهة الخارجية بصريًا في المتصفح.
