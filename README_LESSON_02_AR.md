# مشروع FastAPI حتى المحاضرة الثانية

تم تحديث هذا المجلد من المحاضرة الأولى إلى الثانية من سلسلة Corey Schafer. التشغيل من هذا المجلد:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

- `/` و`/posts`: صفحة المنشورات باستخدام Jinja2.
- `/api/posts`: بيانات المنشورات بصيغة JSON.
- `/docs`: التوثيق التفاعلي.
- `/static/...`: CSS والصور والأيقونات.

اقرأ `LESSON_02_MANUAL_AR.md` للخطوات والأوامر ومحتويات الملفات كاملة. دليل الدرس الأول محفوظ في `README_LESSON_01_AR.md`، ونسخة ما قبل التعديل محفوظة داخل `backups`.

الأصول والقوالب مطابقة لنسخة المدرس المنشورة. Bootstrap والخطوط تُحمّل من CDN كما في المصدر. Login وRegister روابط عرض فقط، ولم تُضف مصادقة أوقاعدة بيانات.
